## Important - read before subscribing

This is **not the original mod**. It is an independent continuation of *Extended Road Upgrades* by ST-Apps, which was last updated for game version 1.4 and no longer loads with game versions 1.5 / 1.6.

**This mod cannot be used together with the original Extended Road Upgrades.** Both register the same upgrade modes and patch the same game methods, so having both enabled duplicates the upgrade modes and produces conflicting road data. Disable or unsubscribe from the original mod and restart the game before using this one.

## Description
This mod enables some additional upgrade modes for your roads, giving you full control on the type of roads you can build without needing to precisely terraform beforehand.

These upgrades are available in the in-game upgrade mode for roads and can be used exactly like any other upgrade mode (e.g. Grass or Wide Sidewalk).

The mod currently supports the following modes:
- Quay
- Retaining Wall
- Elevated
- Tunnel

These upgrades can be applied to:
- Roads
- Pedestrian Paths
- Public Transport Roads
- Train Tracks
- Tram Tracks
- Subway Tracks

## Compatibility
- Supported game versions: 1.5 and newer (developed and tested against 1.6.2).
- Not compatible with the original Extended Road Upgrades mod - the two cannot be enabled at the same time.
- Existing saves keep working. Roads upgraded with the original mod remain valid; just re-apply the upgrade if a road looks wrong.
